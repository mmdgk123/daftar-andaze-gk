# دفتر اندازه کناف

دفتر اندازه برای کارگاه کناف: نقشه را با انگشت روی صفحه‌ی شطرنجی می‌کشی و اندازه‌ها را خودت با ابزار «عدد» روی نقشه می‌نویسی.

نسخه‌ی قبلی: `mmdgk123/daftar-andaze-gk`

## چطور کار می‌کند

- **قلم:** با انگشت بکش؛ خط دستی خودت ذخیره می‌شود.
- **عدد:** روی صفحه بزن، عدد را تایپ کن و «ثبت» را بزن. برچسب اندازه همان‌جا می‌نشیند، با انگشت جابه‌جا می‌شود و با یک ضربه ویرایش یا حذف می‌شود.
- **همان عدد قبلی:** دکمه‌ی میانبر بالای صفحه‌ی عدد، آخرین اندازه را با یک ضربه ثبت می‌کند.
- **برگه‌ی تازه:** یک ضربه؛ بدون فرم و بدون نام‌گذاری. نام برگه خودکار از تاریخ و ساعت ساخته می‌شود و هر وقت خواستی عوضش می‌کنی.
- **برگردان:** وقتی اندازه‌ها را از پشت صفحه (روی زمینه) کشیده‌ای، با یک ضربه روی «⇋ برگردان» نقشه چپ‌وراست می‌شود تا با روی صفحه‌ای که برش می‌خورد بخواند؛ لازم نیست ورق کناف را بگردانی.
- **زوم و جابه‌جایی:** دو انگشت، برای وقتی باید جزئیات را دقیق کشید.

## سرعت

- ابزار «عدد» بعد از هر ثبت فعال می‌ماند؛ ثبت پشت‌سرهم اندازه‌ها بدون تغییر ابزار.
- صفحه‌ی عدد با کیبورد عددی بالا می‌آید و دکمه‌ی ثبتش بالای کیبورد می‌ماند.
- همه‌چیز خودکار ذخیره می‌شود؛ برگشت به فهرست همیشه یک ضربه است.
- «برگه تازه» از داخل منوی برگه هم هست، برای وقتی پشت‌سرهم برش داری.

## خروجی و نگه‌داری

- تصویر برگه برای فرستادن در واتساپ
- پشتیبان JSON از همه‌ی برگه‌ها و بازیابی آن
- حالت روز و شب، فونت آفلاین و سرویس‌ورکر
- انتقال داده‌ی نسخه‌های قبلی در اولین اجرا
