# دفتر اندازه کناف

برنامه‌ی موبایل (PWA) برای یادداشت اندازه و کشیدن شکل صفحات کناف.

- برای هر کار/مشتری یک برگه‌ی جدا
- کشیدن آزاد شکل سقف یا دیوار با انگشت روی صفحه‌ی شطرنجی
- گذاشتن برچسب اندازه (سانتیمتر، با اعشار) روی هر ضلع — قابل جابه‌جایی و ویرایش
- حساب خودکار: مجموع اندازه‌ها به متر و تعداد ورق لازم (متر کل ÷ ۳ متر هر ورق)
- ذخیره‌ی خودکار برگه‌ها در حافظه‌ی گوشی (localStorage)

ساخته‌شده برای کارگاه کناف — mmdGK
